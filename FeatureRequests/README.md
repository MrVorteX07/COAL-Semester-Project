# Feature Requests

Thank you for taking the time to suggest improvements to our project!

## How to Request a Feature

1. Click the "New Issue" button in this repository.  
2. Choose the **Feature Request** template (if available) or use the following format:

---

### Feature Request Template

**Feature Description:**  
A clear and concise description of the feature you want.

**Why is this feature useful?**  
Explain how it improves the project or user experience.

**Additional Context:**  
Any screenshots, sketches, or extra information that may help us understand your idea.

---

We appreciate your contributions and will review all feature requests regularly.
